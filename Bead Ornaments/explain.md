This JavaScript program solves the Bead Ornaments problem using combinatorics. It reads multiple test cases, each containing bead group sizes, and calculates the number of possible tree arrangements. For a single group, it applies Cayley's formula a^(a-2); for multiple groups, it multiplies each group's b_i^(b_i-1) together, then multiplies by total_beads^(groups-2). The modPow() function safely computes large powers using modular arithmetic with BigInt to prevent overflow, returning results modulo 1000000007.
