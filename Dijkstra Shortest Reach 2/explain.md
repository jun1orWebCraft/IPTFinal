This program implements Dijkstra's shortest path algorithm using a custom min-heap priority queue. It builds an undirected graph from edges, then computes shortest distances from node 1 to all other nodes. The MinHeap class maintains efficient insertion and extraction of minimum elements through bubble-up and bubble-down operations. For each node popped from the heap, it relaxes all adjacent edges, updating distances if a shorter path is found and adding updated nodes back to the heap. Finally, it outputs distances for all nodes, returning -1 for unreachable nodes.
