This program implements the Floyd-Warshall algorithm to find shortest paths between all pairs of nodes in a weighted graph. It initializes a distance matrix with edge weights, then iteratively relaxes paths by checking if going through intermediate nodes produces shorter distances. For efficiency, it only considers edges stored in connectedTo and breaks early if no improvements are found in a pass. After computing all-pairs shortest paths, it answers multiple queries by returning the shortest distance between specified node pairs, or -1 if unreachable.
