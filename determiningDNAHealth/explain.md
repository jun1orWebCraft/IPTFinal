This program calculates minimum and maximum DNA health across multiple strands. It preprocesses genes by building a map with prefix sums of health values for efficient range queries, and stores all valid gene prefixes (up to 500 chars) in a set for quick lookup. For each DNA strand query, it iterates through all substrings, checks if they match genes using prefix pruning to avoid unnecessary checks, and uses binary search to count matching genes within the specified health range [first, last], accumulating their total health. Finally, it outputs the minimum and maximum health values found across all strands.
